# アイコンメーカー

画像をブラウザ内だけで切り抜き、円形・正方形のアイコンとして保存できるWebツールです。画像がサーバーへ送信されることはありません。

## 主な機能

- PNG / JPG / WebPのドラッグ＆ドロップ読み込み
- ドラッグ、ホイール、スライダー、ピンチによる位置とズームの調整
- 円形・正方形の切り抜き
- 背景色と縁取りの設定
- リアルタイムプレビュー
- 128 / 256 / 512 / 1024pxのプリセットと16〜4096pxの自由入力
- PNG / JPG / WebP保存とJPG / WebPの品質設定
- 最大50履歴のUndo / Redo
- ダークモード、タッチ操作、キーボード操作

## 開発

Node.js 22.13以上とpnpmを使用します。

```bash
pnpm install
pnpm dev
pnpm build
pnpm test
```

アプリ本体は `app/page.tsx`、スタイルは `app/globals.css` にあります。
